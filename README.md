# Excel VBA Sales Performance Dashboard

이 프로젝트는 Excel VBA를 사용하여 데이터 정리, 피벗 테이블 생성 및 시각적 대시보드 구축을 자동화하는 도구입니다. 복잡한 판매 데이터를 체계적으로 관리하고 한눈에 파악할 수 있는 시각적 보고서를 제공합니다.

## 🚀 주요 기능

1.  **데이터 자동 정제 (`CleanDataFormat.vba`)**
    *   불필요한 빈 행 및 열 제거
    *   텍스트 트림(공백 제거) 및 표준화(Proper Case)
    *   날짜, 통화, 숫자 형식 자동 지정
    *   퍼플 테마(Purple Theme) 기반의 테이블 스타일 적용

2.  **피벗 테이블 자동 생성 (`Pivot.vba`)**
    *   8가지 핵심 분석 지표를 기반으로 한 피벗 테이블 자동 구축
    *   매출 현황, 트렌드, 카테고리별/지역별 성능 분석 등 포함
    *   분석용 데이터 레이아웃 자동 최적화

3.  **시각적 대시보드 구축 (`Dashboard.vba`)**
    *   전문적인 디자인의 대시보드 시트 생성
    *   **KPI 카드:** 총 매출, 이익, 주문 건수 등 핵심 지표 요약
    *   **동적 차트:** 도넛, 라인, 컬럼, 바 차트를 통한 다각도 데이터 시각화
    *   **슬라이서(Slicers):** 연도 및 지역별 필터링 기능 제공
    *   **새로고침 버튼:** 데이터 변경 시 원클릭 업데이트

## 📁 파일 구조

*   `0_Data (3).xlsm`: 매크로가 포함된 실제 작업용 엑셀 파일
*   `CleanDataFormat.vba`: 데이터 클리닝 및 서식 지정 로직
*   `Pivot.vba`: 피벗 테이블 생성 및 구성 로직
*   `Dashboard.vba`: 대시보드 레이아웃 및 차트 생성 로직
*   `README.md`: 프로젝트 가이드 (현재 파일)

## 🛠 사용 방법

1.  **데이터 준비:** `Data` 시트에 원본 데이터를 입력합니다. (Order ID, Order Date, Sales, Profit 등의 열이 포함되어야 합니다.)
2.  **데이터 정제:** `CleanAndFormatData` 매크로를 실행하여 데이터를 깔끔하게 정리하고 테마를 적용합니다.
3.  **분석 준비:** `CreatePivotSheets` 매크로를 실행하여 `Pivot` 시트에 분석용 테이블을 생성합니다.
4.  **대시보드 생성:** `BuildDashboard` 매크로를 실행하여 최종 `Dashboard` 시트를 구축합니다.
5.  **업데이트:** 데이터가 변경되면 대시보드 내의 **"Refresh Dashboard"** 버튼을 클릭하여 최신 상태를 유지합니다.
